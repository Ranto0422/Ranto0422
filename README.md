# Hi, I'm Ryan Torio

Computer Science student at Mapúa Malayan Colleges Laguna. I build full-stack web and mobile apps, from the database and API up to the UI, and I like projects that solve a real scheduling, data or operations problem.

- 🎓 Currently building my capstone, **TARA**: an AI travel assistant app for Laguna Province with a React Native mobile app, a React admin dashboard, and PostgreSQL with PostGIS and pgvector
- 🛠️ Most at home with **React, Django, Kotlin + Jetpack Compose, and PostgreSQL/MySQL**
- 🌱 Learning more about blockchain and web3
